KEY CHANGES IN v3.0 (2026-04-24)

  SCOPE NARROWED
    - Preschool (3–5) removed
    - Secondary (Sec 1–4) removed
    - Focus: Singapore primary market, ages 6–12

  FOUR NEW CRITICAL FEATURES
    1. Data Input — parents upload spelling lists, school calendars,
       assessment dates (.csv / .xlsx / .txt / .ics / .pdf)
    2. SEN Support Framework — ADHD, Autism Spectrum, Other SEN.
       Overlay on grade-band variant. Psychologist review pre-beta.
    3. Mental Health Guardrails — rule-based, suggestion-only,
       parent override. No AI classification. Not clinical.
    4. Sibling Timeline Dashboard — home screen for multi-child accounts

  K2 READINESS MODE
    - Replaces MOE syllabus for K2 children
    - Three pre-built tracks: English, Math, Chinese Foundations
    - Countdown shows "P1 in N days"

  CLAUDE SONNET — 5 USE CASES
    - Model: claude-sonnet-4-6
    - Curriculum parsing, upload parsing, schedule generation,
      bite generation, weak-topic explanation
    - All outputs zod-validated before DB write

────────────────────────────────────────────────────────────────────────────

GRADE BANDS (K2 → P6)

  K2                  Visual-first, readiness tracks, TTS auto,
                      56×56 tap targets, FK ≤ 2

  Lower Primary       P1–P3, guided visual, TTS auto P1–P2,
                      56×56 tap targets, FK ≤ 3

  Upper Primary       P4–P6 (PSLE focus at P6), transitional UI,
                      TTS opt-in, 44×44 tap targets, FK ≤ 6

────────────────────────────────────────────────────────────────────────────

SEN OVERLAYS

  ADHD                5-minute bite cap, focus mode,
                      high-frequency reminders, leaderboard hidden,
                      ABA + CBT frameworks

  Autism Spectrum     48-hour advance notice on schedule changes,
                      motion disabled, predictable cadence,
                      structured routines + social story

  Other SEN           Scaffolded hints, extended response time,
                      parent frustration alert,
                      Vygotsky ZPD framework

  Psychologist review required pre-beta.
  SEN does not alter content — only pacing, structure,
  reward cadence, and notification behaviour.

────────────────────────────────────────────────────────────────────────────

MENTAL HEALTH GUARDRAILS (RULE-BASED)

  overload_risk          Study hours > 2× weekly default
  burnout_risk           Streak drop 3+ consecutive days
  comprehension_plateau  Same topic failed 3+ bites
  activity_imbalance     7+ consecutive study days, no break
  exam_anxiety           < 14 days to exam + completion rate drop

  Suggestions only. Parent always overrides. Never clinical claims.
  Wellbeing dashboard gated to Scholar Pro.

TECH STACK

  Frontend      React 18 + TypeScript + Tailwind + shadcn/ui (PWA)
  Backend       Node.js + Express + TypeScript
  Database      Supabase (PostgreSQL + Auth)
  AI            Claude Sonnet (claude-sonnet-4-6)
  Notifications Telegram Bot API (primary) + Twilio SMS (fallback)
  Offline       Workbox service worker
  Images        Canvas / Puppeteer (1080×1350 WhatsApp cards)
  Hosting       Vercel + Railway + Supabase
  Cron          GitHub Actions (weekly MOE sync)
