# ScholarPath Design System

## Typography

| **Usage** | **Typeface** | **Weight** |
|-----------|-------------|-----------|
| **Headings** | Bevan | Bold |
| **Body Text** | Inter | Regular / Medium |

## Color Palette

| **Role** | **Hex** | **Use Case** |
|---------|--------|------------|
| **Primary** | #3DA3ED | CTAs, branding, active states |
| **Secondary** | #6A7C84 | Borders, disabled states, secondary text |
| **Tertiary** | #C2C6C6 | Light backgrounds, dividers |
| **Dark** | #333333 | Text, dark mode bg, navigation |

## Logo

- Light variant: Dark text + blue mascot on white
- Dark variant: White text + blue mascot on charcoal bg
- Mascot: Robot character (friendly, rounded)

## Application Notes

- Primary blue (#3DA3ED): Gamification badges, streak highlights, exam countdown red state transitions
- Dark gray (#333333): Navigation header, dark mode toggle bg
- Secondary slate (#6A7C84): Disabled buttons, secondary nav items
- Tertiary light (#C2C6C6): Card dividers, skeleton loaders
